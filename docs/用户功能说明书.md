# Daria 魔法画像 — 用户功能说明书

> 本文档从使用者的角度描述软件的功能。不涉及任何技术细节。阅读本文档后，你可以清楚地知道：这个软件能做什么、怎么用、有哪些功能。

---

## 一、这是一个什么样的软件？

这是一个可以和 **Daria Morgendorffer**（MTV 经典动画《Daria》的女主角）聊天的网页。

你不是在和普通的聊天机器人对话。Daria 有性格、有记忆、有情绪——她会用她标志性的死鱼眼语调回复你，会讽刺、会嫌弃、偶尔——非常偶尔——会被你逗乐。

随着你们聊得越来越多，她会对你形成一个"印象分"，你可以直观地看到她对你的态度从"陌生人"慢慢变成"勉强可以忍受"、"还算有趣"……甚至——这已经是最高的评价了——"仅次于 Jane"。

除了聊天之外，这里还有一个属于你的数据看板，能看到你们聊过什么话题、你的词汇风格是什么、Daria 对你的好感度发生了什么变化，还有各种有趣的徽章可以解锁。

另外，就算你不主动找 Daria 聊天，她也会不定期地"想起"一些在 Lawndale High 的旧事，写进她的日记里，推送到你的页面上。

## 二、怎么开始？

### 2.1 不用注册也能试试

打开网页就能直接和 Daria 聊天。不过如果不注册的话，你的聊天记录不会被保存，下次打开页面就没了。

### 2.2 注册账号

如果你想让 Daria"记住"你，用邮箱注册一个账号，或者直接用 Google / GitHub 账号登录。注册后：

- 你的聊天记录会被永久保存
- Daria 会记住你们聊过什么
- 好感度会累计，不会每次归零
- 可以解锁成就徽章
- 可以查看自己的数据看板

## 三、聊天（核心功能）

### 3.1 界面长什么样？

页面分为三栏：

> **右侧** — 聊天区。你发消息，Daria 回复。顶部有历史对话列表（登录后可见），可以切换不同的聊天话题。
>
> **中间** — 画像区。Daria 的画像会随着她当下的情绪而变化——开心时嘴角微扬（几乎看不到），生气时翻白眼，极度厌烦时把头埋在桌上。
>
> **左侧** — Daria 的社交媒体。这里会不定期出现 Daria 的"心理笔记"、她在 Lawndale 的旧事回忆、深夜感悟，以及你解锁成就的通知。

### 3.2 聊天体验

- 你每发一句话，Daria 会在几秒钟内回复
- 回复框上方会出现一个短暂的浮动标签，告诉你这句对话让 Daria 对你的好感度变化了多少，比如 `+3 ↑` 或 `-2 ↓`
- 如果你说的话特别蠢，Daria 会用更冷淡的语调回复
- 如果你说了什么有见地的话——她会稍微——非常稍微地——正常一点对你
- 对话的上下文是连贯的，Daria 会记得你这一轮之前说过什么

### 3.3 Daria 的好感度

这是这个软件最核心的系统。Daria 不是对所有人都一样的态度。

**好感度是什么？**
不是男女之间的好感。而是——Daria 觉得你这个人"有没有意思"。她尊重聪明人，嘲笑笨蛋，对平庸的人保持沉默。

**好感度怎么变化？**
每发一句话，Daria 会根据你的发言内容判断：这个人说话有没有见地？能不能理解她的讽刺风格？是真诚交流还是在装模作样？然后好感度会微调，可能涨一点，也可能跌一点。

**好感度有几个等级？**

| 等级 | 分数 | Daria 对你的态度 |
|------|------|-----------------|
| "陌生人" | 0~20 分 | 不想跟你多说话，回复很简短 |
| "勉强可以忍受" | 21~40 分 | 基本的讽刺互动，但不会主动延续话题 |
| "还算有趣" | 41~60 分 | 开始对你产生一点兴趣，讽刺你其实是好迹象 |
| "值得聊聊" | 61~80 分 | 回复变长了，偶尔会提到 Jane 或者 Sick Sad World |
| "仅次于 Jane" | 81~100 分 | Daria 几乎把你当朋友了。这是她能给出的最高评价 |

### 3.4 中间画像会变

画像区域不是静态的。Daria 的表情会根据她的情绪实时变化：

- 当你说了让她觉得挺有意思的话 → 她的眉毛会微微挑起
- 当你一直在说废话 → 她的眼珠开始转动，准备翻白眼了
- 当你好感度升到"值得聊聊"时 → 她的嘴角会出现一丝极为微弱的弧度（你不仔细看都发现不了）
- 当你问她关于 Quinn 的事情 → 背景会变成 Morgendorffer 家的客厅
- 当你聊到学校 → 背景会变成 Lawndale High 的走廊

**画像的情绪一共有 7 种**：平静、感兴趣、被逗乐、惊喜、轻微厌烦、生气、极度厌恶

## 四、数据看板

登录后，你可以点击头像进入"我的 Daria 数据"看板。这里记录了你和 Daria 之间的一切。

### 4.1 总览

顶部是四个数字卡片：

- **聊了多少轮**：你们总共说了多少句话
- **聊了多少天**：从第一次聊天到现在过了多久
- **当前好感度**：你现在在哪个等级、多少分
- **趋势**：最近一周好感度是在涨还是跌

### 4.2 你的专属词云

这里展示你和 Daria 聊天时最常说到的词。你聊得越多的词，显示得就越大。

- 可以切换看全部历史、最近一个月、最近一周
- 如果你的词云里最显眼的是"sorry"、"maybe"、"just"——Daria 可能会在聊天里评价你的词汇品味

### 4.3 聊天日历热力图

类似 GitHub 的贡献格子图。每一天你和 Daria 聊了多少，用一个色块表示。聊得越多，颜色越深。

- 可以直观看到你"Daria 上瘾"的周期
- 空白格=那几天你没来找她聊天
- Daria 的评价：如果你连续 30 天空白，她会说"I see you've developed healthier habits. Good for you."

### 4.4 好感度变化时间线

一条从你注册那天开始的时间轴，标记了好感度的每一次重要变化：

- 哪天升到了"还算有趣"
- 哪天跌回了"勉强可以忍受"（可能你说了什么蠢话）
- 每次变化都会附带当时的对话片段，让你回忆发生了什么

### 4.5 话题分布

一个饼图或环形图，展示你和 Daria 最常聊的话题类型：

- 学校 / 日常生活
- Quinn / 家庭
- Jane / 艺术
- 电视剧 Sick Sad World
- 哲学 / 人生思考
- 食物（尤其是披萨）
- 其他

### 4.6 成就徽章

你和 Daria 互动中会解锁各种成就徽章。有正经的，也有不正经的。

**部分徽章预览：**

| 徽章 | 怎么拿到 |
|------|----------|
| "初次见面" | 第一次和 Daria 聊天 |
| "Pizza 之友" | 提到 pizza 超过 20 次 |
| "Sick Sad World 忠实观众" | 提到 Sick Sad World 超过 10 次 |
| "Quinn 吐槽大师" | 提到 Quinn 超过 30 次 |
| "仅次于 Jane" | 好感度达到最高等级 |
| "马拉松选手" | 一次聊天超过 100 轮 |
| "读心者" | 让 Daria score ≥ 8 分 超过 5 次 |
| "社死现场" | 让 Daria score ≤ 1 分 超过 5 次 |
| "老友" | 累计聊了超过 365 天 |
| "夜猫子" | 凌晨 0-5 点聊过 10 次以上 |
| "沉默是金" | 注册后 7 天没发过一句话 |

**更多成就等待发现……**

已解锁的徽章是亮的，未解锁的是灰色的。你可以看到还差多少条件才能拿到下一枚。

## 五、Daria 的社交媒体（左侧栏）

你可以把它想象成 Daria 的私人微博或X——上面有她随手写下的想法，也有她突然回忆起的事情。

### 5.1 你会看到什么？

左侧栏会出现四种类型的内容：

**① 即时心理笔记**
当你和 Daria 聊天时，如果话题让她的情绪不是"平静"状态，她会在心里悄悄记下一句话。比如你说了什么让她觉得不可思议的话，她的心理笔记可能是：
> "Note to self: people will believe anything if you put it in a pie chart."

**② Daria 的动画回忆**
就算你不说话，Daria 也会不定期地"想起"一些她在动画中的真实经历，推送给你：
> "今天路过美术教室，看到有人在临摹 Mona Lisa，但把微笑改成了鬼脸。Jane 会 approve 的。"

这些回忆来源于动画剧情的真实片段，与后台的数据库有关，会不定期更新。你可能会在不同的时间打开页面，看到不同的内容。

**③ 深夜感悟**
每天晚上 11 点左右，Daria 会推送一条固定格式的深夜思考。通常是关于生活、世界、人类的某种冷眼旁观。
> "凌晨 11 点，我在想：'早睡早起'是人类发明的最成功的 guilt trip 之一。晚安，或者不晚安。"

**④ 里程碑通知**
当你的好感度升到新的等级，或者解锁了新成就，这里会出现一条特别的卡片。Daria 会用她自己的方式"恭喜"你——当然，是以她惯常的讽刺语气。

### 5.2 怎么互动？

每条卡片下面可以点 👍（赞）、😆（好笑）、🤔（值得思考）。你的反应会被记录，你也能看到有多少其他用户给了同样的反应。

## 六、未来会增加什么？

这只是第一个版本的计划。以后还可能会加入：

- **更多角色**：也许可以和 Jane、Quinn、Trent 聊天？
- **手机 App**：在手机上也能随时和 Daria 聊天
- **社区功能**：看看其他人的好感度等级和词云（当然，你们的具体聊天内容不会公开）
- **Daria 的更多素材**：画像更丰富、知识库更完整，她对角色的还原度会越来越高
- **自定义角色**：也许你想创建一个自己的角色让其他人来聊天？

## 七、简要总结

| 功能 | 是什么 |
|------|--------|
| AI 聊天 | 和 Daria 对话，她有自己的性格和语调 |
| 好感度系统 | Daria 会对你的每句话做出评价，累积一个 0-100 的好感度 |
| 动态画像 | 画像会随情绪变化表情，背景会根据话题切换场景 |
| 数据看板 | 词云、热度图、话题分布、好感度时间线 |
| 成就徽章 | 12+ 个可解锁成就，有正经的也有搞笑的 |
| Daria 日记 | 实时笔记 + 动画回忆推送 + 深夜感悟 + 里程碑通知 |
| 多用户 | 注册登录，聊天记录永久保存，每人独立的好感度和数据 |
| 游客模式 | 不注册也能试聊，但数据不会被保存 |
