# Daria 魔法画像 v2.0 — 实施计划

> 基于《产品需求与架构说明书》制定。不包括图片素材和知识库。

---

## 一、总体策略

### 并行原则

```
Step 0: 基础设施准备
├── 0A: Supabase 项目创建 + 数据库建表    ─┐
└── 0B: Dify 工作流升级（加好感度节点）    ─┤  并行
                                            │
Step 1: 数据层                               │
├── 1A: Supabase 客户端 + 认证服务           │
├── 1B: 数据库 API 层（CRUD 封装）          │  可并行
└── 1C: Dify API 升级（解析 affection）      │
                                            │
Step 2: 核心功能                              │  ↓ 依赖 Step 1
├── 2A: 用户认证 UI（登录/注册/游客）        │
├── 2B: 好感度系统（浮动反馈 + 等级展示）    │  可并行
├── 2C: 聊天历史持久化 + 会话列表            │
└── 2D: 布局调整（左=社交媒体 右=聊天）      │
                                            │
Step 3: 看板 + 社交                           │  ↓ 依赖 Step 2
├── 3A: 数据看板（词云/热力图/时间线/饼图）  │
├── 3B: 成就徽章判定 + 展示                  │  可并行
└── 3C: 社交媒体系统（内容池/定时推送/反应） │
```

## 二、详细任务清单

### Step 0 — 基础设施

| 任务 ID | 内容 | 涉及文件 | 依赖 |
|---------|------|----------|------|
| **0A** | Supabase 项目创建 + SQL 建表 | `supabase/migrations/` | 需要用户提供 Supabase 账号 |
| **0B** | Dify 工作流增加好感度评估 LLM 节点 | `prompts/*.yml` | 无 |

### Step 1 — 数据层

| 任务 ID | 内容 | 涉及文件 | 依赖 |
|---------|------|----------|------|
| **1A** | 安装 Supabase JS SDK，创建客户端、认证服务 | `src/lib/supabase.js`, `src/services/auth.js` | 0A |
| **1B** | 消息/好感度/成就/社交媒体 CRUD 封装 | `src/services/db.js` | 0A |
| **1C** | 更新 difyApi.js 解析 affection_delta | `src/services/difyApi.js` | 0B |

### Step 2 — 核心功能

| 任务 ID | 内容 | 涉及文件 | 依赖 |
|---------|------|----------|------|
| **2A** | AuthModal 组件（登录/注册弹窗）、游客逻辑 | `src/components/AuthModal.jsx`, `src/contexts/AuthContext.jsx` | 1A |
| **2B** | 好感度标签动画、画像旁等级显示 | `src/components/AffectionBadge.jsx`, 改 `ImagePanel.jsx` | 1C |
| **2C** | 聊天记录存 Supabase、会话列表侧边栏 | 改 `ChatPanel.jsx`, 新建 `SessionList.jsx` | 1B, 2A |
| **2D** | 布局左右对调 | 改 `App.jsx` | 无 |

### Step 3 — 看板 + 社交

| 任务 ID | 内容 | 涉及文件 | 依赖 |
|---------|------|----------|------|
| **3A** | 数据看板页面（词云/热力图/时间线/话题饼图） | `src/components/Dashboard.jsx` 及其子组件 | 2C |
| **3B** | 成就定义、判定逻辑、徽章墙 | `src/data/achievements.js`, `src/components/AchievementWall.jsx` | 2C |
| **3C** | 社交媒体卡片组件、反应按钮、推送模拟 | 重写 `JournalPanel.jsx`, 新建 `SocialCard.jsx` | 1B |

## 六、数据库表清单

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| `user_profiles` | 用户扩展信息 | nickname, avatar_url, created_at |
| `chat_messages` | 聊天消息 | user_id, session_id, role, content, score, affection_delta |
| `chat_sessions` | 对话会话 | user_id, title, updated_at |
| `affection_history` | 好感度变化记录 | user_id, score_before, score_after, delta |
| `user_achievements` | 成就解锁记录 | user_id, achievement_key, unlocked_at |
| `daria_social_entries` | 社交媒体内容池 | content, category, pushed |
| `social_reactions` | 用户反应 | user_id, entry_id, reaction |
